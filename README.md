# Marketing Campaign Analytics

End-to-end analytics project for multi-platform marketing campaign data.  
Covers data cleaning, KPI analysis, static visualisations, an interactive Plotly Dash dashboard, and a business insights report.

## Dataset

Place the raw marketing CSV in the **same directory** as `marketing_analysis.py` before running.  
The script auto-discovers any `.csv` file that does not contain `cleaned` in its name.

Expected columns:

| Column | Type | Description |
|---|---|---|
| Campaign_ID | string | Unique campaign identifier |
| Campaign_Name | string | Campaign label |
| Platform | string | Marketing platform |
| Start_Date | date | Campaign start (YYYY-MM-DD) |
| End_Date | date | Campaign end (YYYY-MM-DD) |
| Clicks | numeric | Total clicks |
| Conversions | numeric | Total conversions |
| Cost | numeric | Total spend (USD) |

## Installation

### 1 — Clone / copy the project files

```bash
# Example: unzip the project folder into your working directory
cd ~/my_projects/marketing_analytics
```

### 2 — Create a virtual environment (recommended)

```bash
python -m venv .venv

# macOS / Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

### 3 — Install dependencies

```bash
pip install -r requirements.txt
```

Requires **Python 3.10+**.

---

## How to Run the Analysis

```bash
python marketing_analysis.py
```

What this does:

1. Locates the raw CSV (current directory → `/mnt/user-data/uploads` → script directory)
2. Cleans the data (deduplication, type conversion, platform standardisation)
3. Computes all KPIs and prints them to the console
4. Runs platform and trend analysis with summary tables
5. Exports **`cleaned_marketing_campaigns.csv`**
6. Generates **9 static PNG charts** in `charts/`

Expected runtime: < 10 seconds for datasets up to 50K rows.

---

## How to Run the Dashboard

```bash
python dashboard.py
```

Then open your browser at:

```
http://127.0.0.1:8050
```

> **Note:** Run `marketing_analysis.py` first so that `cleaned_marketing_campaigns.csv` exists.  
> The dashboard will also fall back to reading any raw CSV if the cleaned version is not found.

### Dashboard Pages

| Tab | Contents |
|---|---|
| **Executive Overview** | 6 KPI cards, conversions by platform, cost by platform, campaign donut, conversion rate |
| **Performance Analysis** | CPA, CPC, top-10 campaigns by conversions and by conversion rate |
| **Trend Analysis** | Monthly conversion trend, cost trend, campaign activity bar chart |
| **Platform Ranking** | Composite performance score chart + ranked list with formula |
| **Campaign Data** | Full sortable / filterable data table (top 200 rows) |

### Filters (apply globally to all tabs)

- **Platform** — multi-select dropdown
- **Date Range** — start-date picker (filters by campaign start date)
- **Reset Filters** — one-click reset to defaults

## Troubleshooting

| Issue | Fix |
|---|---|
| `FileNotFoundError: No CSV dataset found` | Place your raw `.csv` in the project directory |
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` |
| Dashboard shows blank charts | Check the filter state — all platforms may be deselected |
| Port 8050 already in use | Edit `dashboard.py` → change `port=8050` to another port |
