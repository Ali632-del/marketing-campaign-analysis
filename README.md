# Marketing Campaign Performance Analysis

## Project Overview
Marketing campaign analysis project using Python and Plotly Dashboard.

## Features
- Data Cleaning
- KPI Analysis
- Trend Analysis
- Platform Ranking
- Interactive Dashboard

## KPIs
- Conversion Rate (CR)
- Cost Per Click (CPC)
- Cost Per Acquisition (CPA)

## Technologies
- Python
- Pandas
- NumPy
- Plotly
- Dash
- Matplotlib
